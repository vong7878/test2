System Guide and User Manual

👤 User Guide (Room Members 104 - 114)

  • Login: Open the website and select your room (e.g. Room 104) from the login popup to start.
  • Device Limitations: Users must access via Mobile / Tablet and be located within Da Nang, Vietnam.
  • Submitting Hygiene Reports:
    • Go to the "Hygiene Report (Member)" menu.
    • Submissions are only allowed on Sundays, from 16:00 - 19:00 (1 time per week).
    • Video Rule: Must use Live Camera Capture only! Do not select from gallery or local files, and video length must not exceed 1 minute (60 seconds).
  • Providing Feedback: Go to the "Feedback" menu to send suggestions which will be sent directly to all 4 admin chats.

⚙️ Admin Guide (Sub-Admins 1, 2, 3)

  • Login: Accessible via computer and mobile by selecting the desired Admin ID and entering the PIN Code (Sub-Admin 1: 1234, Sub-Admin 2: 5678, Sub-Admin 3: 9999).
  • Device Limits: Sub-Admin 1 can login simultaneously on up to 2 devices; Sub-Admins 2 and 3 can login on 1 device per ID.
  • Core Duties:
    • Review and approve reports submitted by members.
    • Use the Admin Work Chat to communicate and monitor user feedback.

👑 Super Admin Guide (Website Creator)

  • Login: Select "Website Creator (Login with Email)" and enter your Firebase email and password.
  • Advanced Management:
    • Add, edit, or delete news and announcements.
    • Add photos or hygiene videos to the Hygiene Tracking page.
    • Adjust Special Points (Add/Sub): Select a room and enter special points to directly adjust room scores.
