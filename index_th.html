👤 คู่มือสำหรับ User (สมาชิกห้องพัก 104 - 114)

  • การเข้าสู่ระบบ: เปิดเว็บไซต์ขึ้นมาแล้วเลือกห้องพักของคุณ (เช่น: ห้อง 104) จากป๊อปอัปเข้าสู่ระบบ เพื่อเริ่มต้นใช้งาน
  • ข้อจำกัดอุปกรณ์: ระบบกำหนดให้ User ต้องเข้าใช้งานผ่าน โทรศัพท์มือถือ (Mobile / Tablet) และ ต้องอยู่ในเขตพื้นที่เมืองดานัง, เวียดนาม เท่านั้น
  • การส่งรายงานความสะอาด:
    • ไปที่เมนู "รายงานความสะอาด (สมาชิก)"
    • ส่งได้เฉพาะ วันอาทิตย์, เวลา 16:00 - 19:00 น. เท่านั้น (1 สัปดาห์ / 1 ครั้ง)
    • กฎเกณฑ์วิดีโอใหม่: ต้อง เปิดกล้องถ่ายสด (Live Camera Capture) เท่านั้น! ห้ามเลือกจาก Gallery หรือ ไฟล์ในเครื่อง และ ความยาววิดีโอ ต้องไม่เกิน 1 นาที (60 วินาที)
  • การแสดงความคิดเห็น: สามารถไปที่เมนู "แสดงความคิดเห็น" เพื่อส่งข้อเสนอแนะ ซึ่งจะถูกส่งตรงถึงห้องแชท Admin ทั้ง 4 คนทันที

⚙️ คู่มือสำหรับ Admin (Admin รอง 1, 2, 3)

  • การเข้าสู่ระบบ: สามารถเข้าได้ทั้งคอมพิวเตอร์และมือถือ โดยเลือกไอดี Admin ที่ต้องการ แล้วป้อน รหัส PIN 4 ตัวเลข (Admin รอง 1: 1234, Admin รอง 2: 5678, Admin รอง 3: 9999)
  • การตรวจสอบอุปกรณ์: Admin รอง 1 สามารถเข้าสู่ระบบพร้อมกันได้สูงสุด 2 เครื่อง ส่วน Admin รอง 2 และ 3 เข้าสู่ระบบได้ 1 เครื่องต่อ 1 ไอดี
  • หน้าที่หลัก:
    • ตรวจสอบ และ อนุมัติรายงาน ที่สมาชิกส่งเข้ามา
    • เข้าใช้งาน ห้องแชทคุยงาน Admin เพื่อสนทนา และ ติดตามความคิดเห็นจากสมาชิก

👑 คู่มือสำหรับ ผู้สร้างเว็บไซต์ (Super Admin)

  • การเข้าสู่ระบบ: เลือก "ผู้สร้างเว็บไซต์ (เข้าด้วยอีเมล)" แล้วป้อนอีเมล และ รหัสผ่าน Firebase ของคุณ
  • การจัดการระบบขั้นสูง:
    • เพิ่ม, แก้ไข หรือ ลบ ข่าวสาร และ ประกาศ ในระบบ
    • เพิ่มรูปภาพ หรือ วิดีโอทำความสะอาดลงในหน้า ติดตามการทำความสะอาด
    • ปรับคะแนนพิเศษ (บวก/ลบ): สามารถเลือกห้องพัก และ ใส่คะแนนพิเศษ เพื่อปรับคะแนนให้แต่ละห้องได้โดยตรง
